## Quick Start

### 1. Clone the Repository

Clone the repository along with its submodule:

```bash
git clone https://github.com/PouLS-PL/stopping-distance-app.git
cd stopping-distance-app
```

### 2. Install Dependencies & Build

Run the installation script from the root directory. This installs all dependencies:
```bash
npm install
```

### 3. Run the Application

Start the backend and the frontend:
```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173/` (or the URL displayed in your terminal) to use the showcase.
