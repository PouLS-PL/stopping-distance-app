# Pierwsze kroki
Aby używać aplikacji, musisz najpierw wprowadzić niezbędne dane. Dotknij ikony koła zębatego w prawym górnym rogu. W polu „Opóźnienie” wpisz opóźnienie, jakie Twój pojazd
osiąga na drodze poziomej o nawierzchni twardej, suchej i czystej. Wpisz wartość w odpowiedniej jednostce (domyślnie m/s<sup>2</sup>).
Po wpisaniu tej wartości aplikacja jest gotowa do użycia.
